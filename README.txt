GitHub 源码：https://github.com/1004zxq/zhiqing

这个文件夹是手机上打开的前端网页，不包含日记和睡眠数据。

网页里的改动会自动保存在当前浏览器的两个位置，不需要手动备份。
连接私人云同步后，数据会先在手机上加密，再自动上传到后端。

v1.4 起支持腾讯云 CloudBase 加密同步：
- 网页先加密，再上传完整数据。
- 服务端只保存密文和版本号。
- 手机、电脑输入同一个同步密钥即可共用数据。
- 点击卡片名字可以查看以前勾选过的具体日期。
- 删除卡片只会把它移出当前列表，以前的勾选和补充记录仍会保留。
